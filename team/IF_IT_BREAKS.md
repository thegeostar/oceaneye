# If it breaks on stage — PRINT THIS

← [START_HERE.md](../START_HERE.md)

**Three rules. Memorise these, not the table.**

1. **Never apologise twice.** One sentence, then move on.
2. **Never go silent.** Somebody is always talking.
3. **Never blame the equipment.** "We planned for this" beats "it's broken".

Judges score *how you recover*. A team that handles a failure calmly can score
**higher** than a team that had no failure at all.

---

## The table

| If this breaks | Say exactly this | Then |
|---|---|---|
| Camera / robot dies | "We will continue with our recorded survey data, collected with this same platform." | S1 opens the backup footage |
| No video reaching laptop | "We will use the survey footage we captured during preparation." | S2 opens the saved file. **Do not debug on stage.** |
| Model crashes | "One moment — we have a verified backup of this run." | S2 plays the backup recording and narrates it live |
| It detects nothing | "The confidence threshold is set high for precision. Let me lower it." | Press the key that drops confidence to 0.20. **Know this keystroke by heart.** |
| Laptop freezes | "We will restart — about forty seconds. Meanwhile, let me explain what you're about to see." | S3 talks while S2 restarts |
| You forget your line | "Let me show you directly." | Walk to the screen and describe what is visible |
| Judge asks something you don't know | "We haven't measured that. What we did measure is…" | Redirect to a number you *have* |

---

## Never say these

| Don't say | Because |
|---|---|
| "This is live" — over a recorded file | Professional Conduct is scored. One follow-up question exposes it. |
| "0.873" | That is her slide's number from a run we don't have. **Say 0.867** — it's in a file we hold. |
| "User authentication" | The login accepts any password. It is a placeholder screen. |
| "We trained this model" | We did not. Prof. Wang did. Attribution is worth points; a bluff costs more. |
| Any number nobody measured | Same reason, every time. |

## Before you walk on stage — 60-second check

- [ ] Wi-Fi **off**, and the demo still runs
- [ ] Backup video on the desktop, and it opens
- [ ] Laptop plugged in, charger in the bag
- [ ] Lens wiped, torch positioned to the side
- [ ] Everyone knows their start time: S1 00:00 · S2 06:30 · S3 13:00
